# Changelog

All notable changes to HarborList are documented here.

## [1.0.0] - 2026-08-31

### Added

- HarborList mooring wait board for Bayline Marina
- MooringBoard, MooringTable, MooringFilter, MooringSearch components
- QueueSummary and SelectionTray widgets
- StatusChip and PriorityMark indicators
- useMooringQueue hook with fetchMoorings API (request IDs, simulated delays)
- Vitest test suite under `tests/`
- GitHub Actions CI workflow
